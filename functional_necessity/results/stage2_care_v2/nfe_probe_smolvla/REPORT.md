# SmolVLA 离线 NFE 探针（CARE v2 480 帧）

完整模型 `lerobot/smolvla_libero`。NFE∈{1,2,3,10} 各自从同一初始噪声独立积分到终点。
参照为同帧、同噪声的 NFE=10。统计前 10 步 × 7 维有效动作，排除 padding。RMSE / 最大绝对误差在模型归一化尺度（MEAN_STD）上计算。
夹爪开合：先反归一化到执行端尺度，再按 LIBERO 惯例 `g>0` 为闭合（dummy/hold-open 为 -1）。
α 与 480 帧映射来自 CARE v2 `shared.pt`，本轮不改 CARE 定义，也不用闭环成功率回拧阈值。

## 正确性

- 速度场调用次数：{'1': 1, '2': 2, '3': 3, '10': 10}。
- 探针 NFE=10（挂钩记录速度场）与正式 `predict_action_chunk` 最大绝对误差 0.0000，判定一致。
- `reset()` 后重复 NFE=10：一致。
- compile 关闭；推理模式；相机 rename 与 8 维 state 与闭环一致。

## 四个问题

**1. 余弦能否区分 NFE=1 和 2？** 均值余弦不能。两个噪声下 NFE=1 为 0.9942/0.9937，NFE=2 为 0.9980/0.9979，都很高。P5 余弦已经能分开：NFE=1 为 0.9849/0.9840，NFE=2 为 0.9948/0.9950。误差、夹爪、尾部仍有稳定差别：RMSE 均值 0.0928/0.0945 → 0.0543/0.0550；尾部 3 步 RMSE 0.0844/0.0847 → 0.0487/0.0496；夹爪任一步不一致 1.2%/1.9% → 0.4%/0.2%。余弦<0.99 的帧从约 11% 降到 1.2%。

**2. 高 α 组是否比同数量随机组更容易出现较大低 NFE 偏差？** 均值误差是，尾部失败率几乎不是。NFE=1 RMSE 均值高 α 0.1129/0.1156，随机 0.0964/0.0997（约高 16%）；RMSE P95 0.1855/0.2149 vs 0.1740/0.2122，差别很小。余弦<0.99 为 16.7%/15.8% vs 16.7%/14.2%，与随机组打平。随机与高 α 重叠 34/120，接近超几何期望 30，对照有效。真正更集中的是窗口内夹爪切换组（56 帧）：NFE=1 余弦<0.99 达 37.5%/33.9%，夹爪不一致 8.9%/10.7%。CARE α 对误差幅度有弱到中等关联，不是干净的关键帧筛选。

**3. 低 α 样本是否也存在明显异常？** 有，但整体更轻。低 α 组 NFE=1 RMSE P95=0.1108/0.1102（全体约 0.16），余弦<0.99 为 4.2%/5.8%，夹爪不一致为 0。预览里的 `long_low`（α=0.290）NFE=1 余弦 0.9778/0.9801，已低于全体 P5。平滑窗口也会出低 NFE 偏差，α 不能当充分筛选器。

**4. NFE=2 是否减轻 NFE=1 的异常，CARE 是否提供额外信息？** 是，减轻很明显。异常定义为该噪声下余弦<全体 P5 或 RMSE>全体 P95 或夹爪任一步不一致。noise0：36 条中 34 条在 NFE=2 不再满足；noise1：37 条中 35 条。NFE=1 异常里高 α 占 52.8%/45.9%（基数 25%），低 α 只占 8.3%/5.4%，随机 33.3%/37.8%。CARE 对「哪些帧更容易出 NFE=1 异常」有约两倍富集，但决定不了哪里必须用满 NFE=10；窗口内夹爪切换的富集更强。闭环 NFE=2 为 82.00%、NFE=1 为 79.25%/78.25%，与动作误差同向，不等于无损。

## 闭环对照（只作背景，不回拧）

完整模型闭环：NFE=10 为 83.00%，NFE=2 为 82.00%，NFE=1 为 79.25%，复跑 78.25%。
动作相似不能解释为闭环无损。本轮只做离线前向。
